# group-data

## Данные группы на графике

**Вариант:** А — посещаемость.

**Данные:** файл `attendance.csv`, 28 студентов × 12 занятий (2026-09-03 … 2026-11-19), 336 ячеек, из них 332 заполнены. Студенты обозначены кодами S01–S28; ФИО и другие идентификаторы в файле отсутствуют, строки перемешаны до присвоения кодов. Данные учебные, сгенерированы случайно (пометка в исходном файле). Исходная таблица с ключом «код → ФИО» в репозиторий не загружалась.

**Выводы:**
1. Средняя посещаемость — 66,9 % (простое среднее по 12 занятиям).
2. Явка по занятиям колеблется от 57,1 % (2026-09-24, 2026-10-15, 2026-10-29) до 82,1 % (2026-10-08).
3. 16 из 28 студентов посетили 75 % занятий и больше, 6 — от 50 до 75 %, 4 — от 25 до 50 %, 2 — меньше 25 %.

**Проверка:** явка занятия 2026-10-08 посчитана вручную в Excel по формуле `=СУММ(…)/СЧЁТ(…)`: 23 / 28 = 82,1 %, на графике — 82,1 %. Файл `attendance.csv` и история коммитов проверены: фамилий нет.
